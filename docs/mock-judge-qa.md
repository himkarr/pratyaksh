# Mock judge Q&A

**Is this a fraud accusation system?** No. It produces confidence-scored, explainable review signals for authorized human auditors.

**Why hybrid AI?** Transparent rules cover known scheme constraints while Isolation Forest identifies unusual synthetic patterns. Each flag labels its origin.

**How do you detect delay early?** The deadline forecaster assesses progress before the mandated 365-day completion deadline, while the rule engine detects actual overdue work.

**How is data protected?** JWT/RBAC limits each role's view; audit events are append-only and linked by hashes. Production deployment requires a protected database, secret management, and real-data governance.
